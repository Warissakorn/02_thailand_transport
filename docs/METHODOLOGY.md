# ระเบียบวิธีการศึกษา (Methodology)

แบบจำลองขนส่งหลายรูปแบบระดับประเทศตามกรอบ **แบบจำลองสี่ขั้นตอน (Four-Step Model)**
พื้นที่ศึกษา: ประเทศไทยทั้งประเทศ · หน่วยวิเคราะห์หลัก: **อำเภอ 928 โซน** (จังหวัด 77 โซน
เป็นการวิเคราะห์ความไว) · ปีฐานเทียบข้อมูลจราจร: พ.ศ. 2565

> สัญลักษณ์: โซน i (ต้นทาง), j (ปลายทาง); โหมด m; T_ij = จำนวนการเดินทาง i→j ต่อวัน

---

## 1. ระบบโซนและโครงข่าย

**โซนวิเคราะห์จราจร (TAZ):** ขอบเขตอำเภอ 928 แห่ง (GADM v4.1 ADM_2) จุดแทนโซน
(centroid) ใช้ **จุดถ่วงน้ำหนักประชากร**:

    centroid_z = ( Σ_c pop_c·x_c / Σ_c pop_c , Σ_c pop_c·y_c / Σ_c pop_c )

โดย c = เซลล์ราสเตอร์ประชากร WorldPop 100 ม. ภายในโซน z จากนั้น snap เข้าโครงข่ายถนนสายหลัก

**โครงข่ายถนน:** OSM ชั้น tertiary ขึ้นไป 141,469 ช่วง (158,104 กม.) แปลงเป็นกราฟโดย
**การแบ่งจุดต่อ (noding)**: จุดยอดเป็น node เมื่อเป็นปลายเส้นหรือถูกใช้ร่วมโดย ≥2 เส้น
(รองรับสามแยกรูป T) ได้กราฟ 160,026 nodes / 202,781 edges เชื่อมโยง (weak) 98.2%
กราฟเป็น**แบบมีทิศ (directed)**: edge ทางเดียวตามแท็ก `oneway` ของ OSM (61.6% ของ edge —
ทางหลวงสายหลักเป็นทางคู่แยกทิศ)

ความเร็วอิสระ (free-flow) ต่อช่วง: ใช้ `maxspeed` ของ OSM ถ้ามี ไม่งั้นตามชั้นถนน
(motorway 110, trunk 90, primary 80, secondary 70, tertiary 60 กม./ชม.)
ความจุรายชั่วโมง: cap = c₀·เลน โดย c₀ ตามชั้นถนน (motorway 2,000 … tertiary 1,000
PCU/ชม./เลน; ตามแนวปฏิบัติ HCM) เวลาเดินทางต่อ edge: t = (ระยะ/ความเร็ว)

**โครงข่ายโหมดอื่น:** ราง (OSM railway, ความเร็ว 80/60/40 กม./ชม. ตามประเภท),
เรือโดยสาร (OSM ferry, 30 กม./ชม.), เดินเรือชายฝั่งสินค้า (ท่าเรือหลัก 10 แห่ง +
เส้นเชื่อม 9 เส้น, 25 กม./ชม.), อากาศ (สนามบิน 41 + เส้นทางบินภายในประเทศ 50 คู่;
เวลาบิน = 30 นาที + ระยะ/750 กม./ชม.)

**ตัวเชื่อมเข้าถึง (access/egress connector):** จากทุกโซนไปยัง terminal ใกล้สุดของแต่ละโหมด
(สถานีรถไฟ/สนามบิน/ท่าเรือ) เวลา access = ระยะตรง × 1.3 (detour factor) ÷ 50 กม./ชม.

## 2. ขั้นที่ 1: การเกิดการเดินทาง (Trip Generation)

ผู้โดยสาร (Production/Attraction ต่อโซน i):

    P_i = r · POP_i
    A_i = T_P · (0.7·POP_i/ΣPOP + 0.3·SCH_i/ΣSCH)

สินค้า:

    P_i^F = T_F · (0.8·IND_i/ΣIND + 0.2·POP_i/ΣPOP) ,   T_F = f_F · T_P
    A_i^F = T_F · (0.5·IND_i/ΣIND + 0.5·POP_i/ΣPOP)

โดย POP = ประชากร (WorldPop), SCH = จำนวนสถานศึกษา (OSM), IND = พื้นที่อุตสาหกรรม
ตร.กม. (OSM landuse)

**การปรับเทียบขนาด:** r (อัตราการเดินทาง) และ f_F ปรับด้วย least-squares ให้ปริมาณจราจร
จำลองเทียบ AADT มี scale factor k→1 (แยกฝั่งผู้โดยสาร/สินค้า จากปริมาณ PCU รายชนิดรถ
ของสถานี AADT) ได้ **r = 0.0661, f_F = 0.1616**

> ⚠️ การตีความ r: มิใช่อัตราการเดินทางเชิงพฤติกรรม (คนไทยเดินทาง ~2 เที่ยว/วัน) แต่เป็น
> **สัดส่วนอุปสงค์ที่ปรากฏบนโครงข่ายทางหลวงสายหลักระหว่างโซน** — การเดินทางส่วนใหญ่เป็น
> ระยะสั้นภายในพื้นที่/บนถนนท้องถิ่นที่ไม่อยู่ในแบบจำลอง (ดู LIMITATIONS)

## 3. ขั้นที่ 2: การกระจายการเดินทาง (Trip Distribution)

แบบจำลองแรงโน้มถ่วงเงื่อนไขคู่ (doubly-constrained gravity) ฟังก์ชันต้านทานเอกซ์โพเนนเชียล:

    T_ij = a_i·P_i · b_j·A_j · exp(−β·c_ij)

c_ij = เวลาเดินทางถนนสั้นสุด (นาที, Dijkstra บนกราฟ directed) ; a_i, b_j จากการทำสมดุล
แบบ Furness จนลู่เข้า ; ต้นทุนภายในโซน c_ii = 0.5·min_j(c_ij)

**การปรับเทียบ β:** grid search แยกสาย เทียบ R² ของปริมาณจำลอง (all-or-nothing)
กับ AADT รายสถานี ณ พิกัด v2 → **β_pax = 0.025, β_frg = 0.008** (ต่อ 1 นาที)

## 4. ขั้นที่ 3: การเลือกรูปแบบการเดินทาง (Mode Choice)

Multinomial logit บนต้นทุนรวมประตูถึงประตู (generalized cost, นาทีเทียบเท่า):

    GC_m = ASC_m + transfer_m + t_access + t_ivt·f_ivt + t_egress + fare_m/VOT
    Pr(m) = exp(−θ·GC_m) / Σ_k exp(−θ·GC_k) ,  θ = 0.02

- **สองกลุ่มมูลค่าเวลา (2-segment VOT):** ทั่วไป 180 บาท/ชม. (88%) และธุรกิจ 600 บาท/ชม.
  (12% ของการเดินทางระหว่างโซน) — จำเป็นต่อการจับอุปสงค์เครื่องบิน
- ชุดโหมดผู้โดยสาร: รถยนต์, จักรยานยนต์ (เฉพาะทริป ≤90 นาที — สมมติให้เป็นโหมดระยะสั้น),
  รถโดยสาร, รถไฟ, เครื่องบิน, เรือ ; ภายในโซน: โหมดถนนเท่านั้น
- ชุดโหมดสินค้า: รถบรรทุก, รถไฟ, เรือชายฝั่ง
- ค่าโดยสาร (บาท/กม.): รถยนต์ 1.5 (หารผู้โดยสารเฉลี่ย), จยย. 1.0, รถโดยสาร 0.5, รถไฟ 1.0,
  เรือ 1.5, บรรทุก 4.0; เครื่องบิน 1,200 + 3.0/กม.

**การปรับเทียบ ASC:** iterative proportional fitting

    ASC_m ← ASC_m + (1/θ)·ln( share_m^model / share_m^target )

เป้าหมายทางการปี 2565: ผู้โดยสารระหว่างเมือง (สนข./แบบจำลอง NAM: รถยนต์ 84.9%,
รถโดยสาร 11.9%, รถไฟ 1.13%, เครื่องบิน 2.16%) และสัดส่วนตันสินค้าในประเทศ
(สนข.: ถนน 86.7%, ราง 1.71%, น้ำ 11.6%) — ลู่เข้าภายใน ±0.5 จุด

## 5. ขั้นที่ 4: การแบ่งปริมาณจราจร (Trip Assignment)

**อุปสงค์ถนนรวม** = การเดินทางประตูถึงประตูด้วยโหมดถนน (แปลงเป็น PCU: รถยนต์ 1.0,
จยย. 0.33, รถโดยสาร 2.5, บรรทุก 2.0) **+ ช่วง access/egress บนถนน**ของผู้ใช้ราง/อากาศ/น้ำ
(โซน↔terminal; ผู้โดยสารเป็นรถยนต์ PCU 1.0, สินค้าเป็นรถบรรทุก PCU 2.0)

**ชั่วโมงเร่งด่วน:** OD_peak = K·OD_วัน โดย K = 0.09 (สมมติฐานตามแนวปฏิบัติ
การวิเคราะห์ทางหลวง; design-hour factor)

**สมดุลผู้ใช้ทาง (user equilibrium) แบบ MSA:** เวลาแออัดตามฟังก์ชัน BPR

    t_e(v) = t0_e · (1 + 0.15·(v_e/cap_e)^4)
    x^(n) = x^(n−1) + (1/n)·(y^(n) − x^(n−1))

**การโหลดขั้นสุดท้าย = multi-path per-component MSA**: แต่ละรอบ assign ทั้ง 7 องค์ประกอบ
(d2d-คน, d2d-สินค้า, access ราง-คน/สินค้า, อากาศ-คน, น้ำ-คน/สินค้า) ที่เวลาแออัดปัจจุบัน แล้ว
MSA-average (วน 8 รอบ — หนักกว่ารอบละ ~4x จึงลดจาก 20) → flow **กระจายหลายเส้นตามสมดุล**
(แก้ปัญหา AON snapshot เดิมที่โยนทุก OD ลงเส้นสั้นสุดเส้นเดียว ทำให้สายขนาน flow=0) ; เพราะ
assignment เป็น linear ต่อ demand ทุกรอบ ผลรวม 7 องค์ประกอบ = ปริมาณรวม**เป๊ะ** (additivity 0.000000%)
> ทำผ่าน `lib/passign.py` (multiprocessing) — flow แต่ละ origin อิสระ+บวกกันได้ → ผลเท่า serial
แล้วขยายกลับเป็นรายวันด้วย 1/K

## 6. การปรับเทียบและการตรวจสอบ (Calibration & Validation)

**พิกัดสถานี AADT (วิธี v2):** สถานีระบุด้วยเลขสายทาง+กม. (ไม่มีพิกัด) → รวมทุกช่วง OSM
ของสายนั้นทั่วประเทศ, ใช้แนวยาวสุด, วางสถานีตามระยะ กม. สัมบูรณ์ (chainage) โดยเลือกทิศ
ที่ทำให้สถานีตกใน**จังหวัดที่ระบุ**มากที่สุด (การ validate ในตัว; ผ่าน 39.9%) ที่เหลือ
interpolate รายจังหวัด (fallback) รวมวางได้ 2,547/2,701 สถานี (94%)

**PCU ฝั่งสังเกต:** จากปริมาณรายชนิดรถ 13 ชนิดของกรมทางหลวง แปลงด้วย PCU:
รถยนต์นั่ง 1.0, โดยสารเล็ก/กลาง/ใหญ่ 1.5/2.0/2.5, จยย. 0.33, บรรทุก 4 ล้อ/6 ล้อ/10 ล้อ/
พ่วง/กึ่งพ่วง 1.5/2.0/2.5/3.0/3.0 — แยกเป็น PCU ผู้โดยสาร/สินค้า เพื่อปรับเทียบสองสายแยกกัน

**ตัวชี้วัด:**

    GEH = √( 2(M−C)² / (M+C) )   (M = จำลอง, C = นับจริง; เกณฑ์ที่ยอมรับ GEH<5 ≥85% ของสถานี)
    R², RMSE, k (least-squares scale through origin)
